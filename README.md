# 🎮 Fortnite OG — Chapter 1

**Drop in. Loot up. Build. Survive.**

A web-based recreation of the classic Fortnite OG experience, inspired by Chapter 1's original gameplay, building mechanics, weapons, environments, and iconic visual style.

Experience the classic Battle Royale formula directly in your browser, with no traditional game engine required.

---

## 🌍 Overview

Fortnite OG brings back the classic Chapter 1 atmosphere with a stylized 3D world, fast-paced combat, resource gathering, and real-time building.

Built with modern web technologies, the project aims to recreate the original Fortnite gameplay experience in a browser-accessible format.

### ✨ Features

- **Classic OG Visual Style** — Stylized environments, colorful landscapes, and the iconic Chapter 1 atmosphere.
- **Third-Person Gameplay** — Explore the map with responsive movement, jumping, and camera controls.
- **Classic Weapons** — Assault rifles, pump shotguns, SMGs, sniper rifles, and the pickaxe.
- **Building System** — Place walls, floors, ramps, and roofs during gameplay.
- **Resource Gathering** — Harvest materials and use them to construct defensive structures.
- **Inventory & HUD** — Weapon slots, ammunition, health, shield, and building materials.
- **3D Environments** — Explore buildings, terrain, and outdoor locations.
- **Browser-Based** — Play directly from a supported web browser.
- **Performance Optimization** — Efficient rendering and asset management for web environments.

## 🕹️ Controls

| Key | Action |
|---|---|
| `W` `A` `S` `D` | Move |
| `Mouse` | Look around and aim |
| `Space` | Jump |
| `Shift` | Sprint |
| `Left Click` | Shoot / use pickaxe / place building |
| `Right Click` | Aim / cancel building preview |
| `R` | Reload / rotate building piece |
| `1–5` | Select inventory slot |
| `Q` | Toggle building mode |
| `Z` | Wall |
| `X` | Floor |
| `C` | Ramp |
| `V` | Roof |
| `Esc` | Pause |

*Controls may vary depending on the implemented version.*

## 🚀 Getting Started

### Play Online

Open the project's GitHub Pages deployment, if available, to play directly in your browser.

### Run Locally

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
cd YOUR_REPOSITORY_FOLDER
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

### GitHub Pages

Deployment depends on the project's Next.js configuration. A static export may be required, and features that depend on server-side functionality may need adaptation.
